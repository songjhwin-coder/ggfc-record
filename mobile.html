팀 전력과 별점 계산 기준

선택한 조회 날짜까지 적용된 최신 시즌에서 팀별 가장 최근 스쿼드를 사용합니다. 미래 적용 명단은 적용일부터 표시합니다. 선수 능력치도 선택한 조회 날짜까지의 경기·SoccerBee 측정 이력을 기준으로 계산합니다.

구성원별 공격 = SHO 45% + PAC 25% + DRI 20% + PHY 10%
중앙 = PAS 45% + DRI 30% + PHY 15% + DEF 10%
수비 = DEF 55% + PHY 30% + PAC 15%
팀별 각 점수는 평가 가능한 구성원의 동일비중 평균, TEAM 점수는 세 항목 평균입니다. 별점은 점수÷20을 0.5 단위로 반올림합니다(80점=4.0, 85점=4.5). 표시 점수는 소수점 첫째 자리입니다.

선수명단에 등록된 감독·코치도 구성원으로 포함합니다. 미등록·참여 시작 전 선수는 명단에 표시하되 평균에서 제외합니다. SoccerBee 미측정자는 기존 능력치 기본값이 포함되며 별도 표시합니다. 포지션은 선수명단에서 읽으며 포지션별 인원수 가중은 적용하지 않습니다. 이 팀 전력은 비교용 설계 지표이며 실제 승률 예측값이 아닙니다.

SoccerBee 최신 측정 현황
마지막 업로드 엑셀에 있는 측정 이력만 저장합니다. 엑셀에서 지운 행은 재업로드 시 삭제됩니다. 선수명은 통합 선수명단 DB와 자동 매칭합니다. 능력치 계산에는 선수명단 DB의 이름과 매칭한 뒤 축별 최신 유효 측정을 사용하며, 고정 절대평가 기준표로 PAC·DRI·DEF·PHY를 계산합니다. 현재 모델은 평균속도·가속감속액션·고강도 가속을 추가 사용하며, 참가자 상대평가는 능력치 결정에 사용하지 않습니다.
적용 원칙: 선수명단 DB 이름 매칭 → 일자 합산 → 축별 최신 유효 평가. 이전 측정값은 History로 보존하며, 상대 백분위는 참고용으로만 사용합니다.

선수 능력치 등록 및 초기화
SoccerBee 측정 이력을 등록하고 선수카드에 적용할 능력치 시스템을 관리합니다.

통합 기록지 선수명단을 먼저 등록하세요. 업로드할 엑셀에 유지할 전체 측정 이력을 포함하세요. 엑셀에서 삭제한 행은 DB에서도 삭제됩니다. 양식 헤더만 있는 빈 엑셀은 사커비 DB를 비웁니다. 잘못된 값·선수명·중복 충돌은 전체 업로드를 취소하고 기존 DB를 유지합니다.

SoccerBee DB 초기화는 측정 이력만 삭제합니다. 경기기록과 선수명단은 유지합니다.

ℹ️현재 적용값: 모든 가산치·배율·기본점수는 관리자 전용 능력치 설정 메뉴의 저장값을 사용합니다. SoccerBee 미평가 점수는 실력 평가가 아닌 미측정 기본값입니다.

선수 능력치 설정

선수 능력치 계산에 사용하는 시작값 · 출석 연간 한도 · 기록 성장 요율 · 최근 5경기 FORM · 지속 부진 보정 · SoccerBee 환산률 · 포지션별 OVR을 관리자 기준으로 조정합니다. 현재 저장된 설정을 설명자료와 계산에 함께 적용합니다.

⚙️설정 변경은 저장 후 즉시 선수 능력치와 선수카드 재계산에 적용됩니다. 기본값 복원을 누르면 현재 버전 기준값으로 되돌릴 수 있습니다.

한 줄 = 한 경기의 한 팀. 경기기록의 대회는 슈퍼리그·챌린지리그·인터리그로 입력합니다. 같은 경기의 양쪽 팀 행에는 같은 대회명을 적습니다. 경기기록에서는 반기·그룹 열을 생략하고, 경기일 당일 또는 이전의 최신 팀스쿼드에서 자동 적용합니다. 팀스쿼드의 그룹은 팀 리그 소속을 뜻하며 A 또는 슈퍼리그는 슈퍼리그, B 또는 챌린지리그는 챌린지리그로 반영됩니다. 그룹은 날짜별로 달라질 수 있으며 종합기록 조회 날짜를 바꾸면 해당 날짜의 그룹으로 팀 구성이 자동 변경됩니다. 팀스쿼드 반기는 상반기·하반기, 라운드는 R1·R2처럼, 경기번호는 구장까지 포함해 1A·1B로 적습니다. 기존 DB의 라운드=1경기, 경기번호=13R-A 형식도 지원하며, 이 경우 13R을 기준 라운드로 읽습니다. 몰수패한 팀은 몰수패 칸에 몰수패라고 입력하면 실제 득점과 관계없이 해당 팀은 패배, 상대팀은 승리로 판정됩니다. 득점자·도움·개인파울·선방·MOM은 김철수 2, 최민수 1처럼 이름과 횟수를 쉼표로 적습니다. 개인파울은 DEF 감점과 해당 경기·팀의 팀파울 합계에 반영합니다. 개인파울 기록이 있으면 선수별 합계를 팀파울로 사용하고, 없으면 기존 파울수 값을 사용합니다. 두 값을 더하지 않으며, 개인파울을 입력할 때는 해당 팀의 모든 개인파울을 기록해 주세요. MOM은 해당 Round 1회 장기 성장에 사용합니다. 출석한 선수는 경기기록의 선수1~15 칸에 적습니다. 팀스쿼드는 A열 날짜부터 다음 변경 전까지 적용하며 감독·코치·선수 전체를 표시하고 실제 출석자만 굵게 표시합니다. 선수명단의 시작일자 이전에는 능력치 결석 감점을 적용하지 않습니다. 시즌 열의 출전 표기는 연도와 별도로 보존합니다. 감독·코치도 경기일에 유효한 팀스쿼드 항목으로 적용합니다. 경기기록의 감독 칸은 판정에 사용하지 않습니다. 반기 전환·승강·팀 이동이 있으면 변경일의 팀스쿼드를 새 행으로 추가하세요. 팀스쿼드 누락, 양 팀 반기 불일치, 대회·그룹 불일치는 업로드를 중단하고 기존 DB를 유지합니다. 감독이 직접 선수로 뛰었다면 선수 칸에도 이름을 적어야 출석률에 반영됩니다. 같은 날짜·대회·라운드·경기번호·대진의 두 행이 한 경기로 묶이고, 출석률·득점 누계는 선수명단과 자동 연동됩니다. 업로드 후 가장 최근 경기일이 종합기록에서 바로 열립니다. 선수카드 등급 조건

Career Achievement 통산 기준입니다. 각 등급에서 지정한 개수만큼 조건을 달성하면 승급합니다. IRON은 기본 등급이며 OVR·능력치는 변경되지 않습니다.

IRON → BRONZE → SILVER → GOLD → PLATINUM → DIAMOND → MASTER → CHALLENGE의 8단계입니다. 항목별 기준은 상위 등급일수록 같거나 크게 입력하세요. 상위 등급의 필요 조건 수는 하위 등급 이상이어야 합니다. 변경하면 모든 선수의 현재·과거 카드 등급이 새 기준으로 재계산됩니다.

선수 카드 디자인

8개 등급마다 디자인을 선택합니다. 승급하거나 과거 기록을 조회하면 해당 등급의 디자인이 자동 적용됩니다. 능력치는 변경하지 않습니다.

선수카드는 선수명단의 사진(URL) 배경삭제 열을 우선 사용합니다. 빈칸이거나 불러오지 못하면 사진(URL)을 사용합니다. 투명 PNG·WebP 링크를 입력한 후 엑셀을 다시 업로드하세요.

앱 시작 화면

앱을 처음 실행할 때만 표시하는 시작 화면입니다. 기록 조회·갱신과 별개로 설정한 시간 동안 표시합니다.

저장 후 회원에게 공통 적용됩니다. 이미 접속한 기기는 최신 설정을 받은 다음 실행부터 반영됩니다. 이미지 전체를 원래 비율로 표시하고, 설정한 시간이 지나면 자동으로 닫힙니다. 데이터는 시작 화면 뒤에서 준비하며, 메뉴 이동·기록 갱신·앱 새로고침에서는 시작 화면을 다시 띄우지 않습니다. 앱을 새로 실행할 때만 표시합니다. 등록한 사진 중 한 장을 앱 실행마다 동일한 확률로 무작위 표시합니다. 같은 사진이 연속으로 나올 수도 있습니다. 등록 사진이 없으면 기본 이미지를 표시합니다. 사진은 자동 압축하며 전체 등록 용량은 약 1.5MB 이내입니다.

화면 비율에 따라 상하 또는 좌우 여백이 표시됩니다.

표시명만 변경되며 엑셀 DB의 그룹 판정(A/B), 경기 기록과 통계 계산 방식은 변경되지 않습니다.

기존 비밀번호는 조회할 수 없습니다. Firebase 프로젝트 관리 권한으로 새 비밀번호를 설정하는 방식으로 복구합니다.

현재 고정 관리자 계정은 ggfc-admin@example.com입니다. 메일을 받을 수 없는 주소이므로 비밀번호 재설정 메일로 복구할 수 없습니다.

  1. 이 프로젝트를 관리하는 Google 계정으로 Cloud Shell을 엽니다.
  2. 아래 복구 도구를 내려받아 Cloud Shell의 파일 업로드로 올립니다.
  3. 아래 진단 명령을 실행하고 프로젝트·권한·관리자 계정 조회 결과를 확인합니다.
  4. 관리자 계정 조회가 성공하고 변경 권한이 확인되면 재설정 명령을 실행합니다. 새 비밀번호를 두 번 입력하고 최종 확인한 뒤 앱에 로그인합니다.
