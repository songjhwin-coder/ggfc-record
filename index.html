선수 능력치

선수 능력치는 매 Round 새로 발생한 경기 이벤트를 1회씩 장기 누적합니다. SHO 득점 성장은 골당 고정 가산값으로 상한 없이 누적하며, FORM 기능은 사용하지 않습니다. Career 시작일 이후 선수 소속팀의 첫 경기 Round부터 미출전 시 능력치별 결석 감점이 Career에 1회 반영됩니다. 선수 능력치 화면의 출석R + 누적 결석R은 항상 해당 반기/선택 기준일까지의 최종 Round 번호와 같도록 계산합니다. 내부 계산은 소수점으로 누적하되 선수카드와 능력치 표시는 반올림하지 않고 내림합니다. 결석은 선수 소속팀이 실제 경기한 날만 판정하고, SoccerBee 첫 측정값은 실제 측정일에 적용합니다.

선수 능력치 조회 및 등록
상반기/하반기의 Round 수는 고정하지 않습니다. · 1Round는 해당 경기일의 팀별 경기 기록을 합산합니다.
ℹ️현재 적용값: 모든 가산치·배율·기본점수는 관리자 전용 능력치 설정 메뉴의 저장값을 사용합니다. SoccerBee 미평가 점수는 실력 평가가 아닌 미측정 기본값입니다.
최근 능력치 상승 선수
직전 경기일 대비 PAC·SHO·PAS·DRI·DEF·PHY 또는 OVR이 정수 기준 1점 이상 상승한 선수만 표시합니다.
선수 능력치 현황
선택 시즌의 상반기와 하반기를 각각 구분해 표시합니다. 경기 날짜를 선택하면 해당 경기 종료 시점의 능력치를 조회합니다.

SoccerBee 최신 측정 현황
업로드한 측정 이력은 삭제하지 않고 보존하며, 첨부 DB 1행의 23개 항목을 모두 저장합니다. 선수명은 통합 선수명단 DB와 자동 매칭합니다. 능력치 계산에는 선수명단 DB의 이름과 매칭한 뒤 가장 최근 날짜 1건을 사용하며, 고정 절대평가 기준표로 PAC·DRI·DEF·PHY를 계산합니다. 현재 모델은 평균속도·가속감속액션·고강도 가속을 추가 사용하며, 참가자 상대평가는 능력치 결정에 사용하지 않습니다.
적용 원칙: 선수명단 DB 이름 매칭 → 최신 1건 → 고정 절대평가. 이전 측정값은 History로 보존하며, 상대 백분위는 참고용으로만 사용합니다.

선수 능력치 설정

선수 능력치 계산에 사용하는 초기능력치 산정 · 골당 SHO 가산 · Round 이벤트 성장값 · 결석 능력치 감점 · SoccerBee 환산률 · 포지션별 OVR을 관리자 기준으로 조정합니다. V3.17은 기존 능력치 기본값을 유지하며, 라운드 인식·출석 집계·조회기간 오류를 보완했습니다.

⚙️설정 변경은 저장 후 즉시 선수 능력치와 선수카드 재계산에 적용됩니다. 기본값 복원을 누르면 현재 V3.17 기준값으로 되돌릴 수 있습니다.

데이터 관리

엑셀 통합 기록지 한 파일로 모든 기록을 올립니다. 업로드가 끝나면 가장 최근 경기일의 기록이 종합기록에 자동 표시됩니다. 편집은 관리자만 가능합니다.

ℹ️관리자 계정에서 변경한 기록과 설정은 공유 서버에 저장됩니다. 상단의 “공유 저장 완료”를 확인한 뒤 닫아 주세요. 회원 화면에는 자동으로 반영됩니다.

📗 GGFC 통합 기록지 — 엑셀 1개 파일

경기기록 · 팀스쿼드 · 선수명단 · 스페셜기록 네 시트가 들어 있는 엑셀 한 파일로 관리합니다.
한 줄 = 한 경기의 한 팀. 그룹은 해당 경기일의 팀 리그 소속을 뜻하며 A 또는 슈퍼리그는 슈퍼리그, B 또는 챌린지리그는 챌린지리그로 반영됩니다. 그룹은 날짜별로 달라질 수 있으며 종합기록 조회 날짜를 바꾸면 해당 날짜의 그룹으로 팀 구성이 자동 변경됩니다. 반기는 상반기·하반기, 라운드는 R1·R2처럼, 경기번호는 구장까지 포함해 1A·1B로 적습니다. 기존 DB의 라운드=1경기, 경기번호=13R-A 형식도 지원하며, 이 경우 13R을 기준 라운드로 읽습니다. 몰수패한 팀은 몰수패 칸에 몰수패라고 입력하면 실제 득점과 관계없이 해당 팀은 패배, 상대팀은 승리로 판정됩니다. 득점자·도움·개인파울·선방·MOM은 김철수 2, 최민수 1처럼 이름과 횟수를 쉼표로 적습니다. 개인파울은 DEF 감점과 해당 경기·팀의 팀파울 합계에 반영합니다. 개인파울 기록이 있으면 선수별 합계를 팀파울로 사용하고, 없으면 기존 파울수 값을 사용합니다. 두 값을 더하지 않으며, 개인파울을 입력할 때는 해당 팀의 모든 개인파울을 기록해 주세요. MOM은 해당 Round 1회 장기 성장에 사용합니다. 출석한 선수는 경기기록의 선수1~15 칸에 적습니다. 팀스쿼드는 A열 날짜부터 다음 변경 전까지 적용하며 감독·코치·선수 전체를 표시하고 실제 출석자만 굵게 표시합니다. 선수명단의 시작일자 이전에는 능력치 결석 감점을 적용하지 않습니다. 시즌 열의 출전 표기는 연도와 별도로 보존합니다. 감독 칸은 누가 감독인지만 확인하는 칸입니다. 감독이 직접 선수로 뛰었다면 선수 칸에도 이름을 적어야 출석률에 반영됩니다. 같은 날짜·대회·라운드·경기번호·대진의 두 행이 한 경기로 묶이고, 출석률·득점 누계는 선수명단과 자동 연동됩니다. 업로드 후 가장 최근 경기일이 종합기록에서 바로 열립니다.
