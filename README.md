## 1. Overview 조회기간

이전에는 랭킹 조회기간을 지정해도 집계 과정에서 반기 전체로 다시 바뀌었습니다. 관리자 모드는 선택된 시작·종료일을 포함하는 경기만 사용하도록 수정했습니다.

- 득점랭킹, 참석률랭킹, 팀 순위 및 누적 기록, 대표승점·누적참석수·누적승점, 개인승점순위, 팀파울순위에 같은 랭킹 범위를 적용합니다.
- 시즌, 상·하반기, 구간, 시작·종료일 변경 시 즉시 결과를 갱신합니다. 조회 적용 버튼도 유지합니다.
- 상대전적은 별도의 상대전적 조회기간을 그대로 적용합니다. 랭킹 기간과 독립적으로 비교할 수 있습니다.
- 대표승점은 선택기간 안에 **전체가 포함된 확정 구간**만 합산합니다. 구간 일부만 조회한 경우 전체 구간에 부여된 대표승점을 임의로 나누거나 이월하지 않습니다. 따라서 일자 조회에서 대표승점이 0일 수 있습니다. 실제 경기승점은 해당 날짜의 승 3·무 1·패 0을 합산합니다.
- 경기일별 결과의 날짜 선택과 랭킹 기간 선택은 서로 다른 용도입니다. 경기결과 날짜를 바꿔도 관리자가 설정한 별도 랭킹 기간을 덮어쓰지 않습니다.
- 열람모드에서는 실제 등록된 경기일 선택과 최신 날짜 버튼을 제공합니다. 달력 직접 입력은 관리자에게만 보입니다.
- 열람모드의 상대전적·랭킹은 선택 경기일이 속한 시즌의 상반기 또는 하반기 **전체**입니다. 해당 구간이나 선택일까지의 누적이 아닙니다.
- Overview의 Match Calendar 이동 버튼을 제거했습니다.

## 3. 골키퍼 기록

### 입력

경기기록 **O열 `키퍼실점`**:

- `임일규-3(15)` 또는 `임일규3(15)` → 3실점, 키퍼 수행 15분
- `임일규0(7:30), 남진전1(7.5)` → 7분 30초씩 수행
- 여러 선수는 쉼표, 세미콜론, 줄바꿈으로 구분합니다.
- 실점은 0 이상의 정수, 시간은 양수입니다. 실제 무실점은 `0(15)`처럼 0을 명시합니다.

팀별 기록지 **`선방`**: 해당 날짜·경기번호·라운드·팀명·선수에 대한 선방 횟수를 입력합니다. 빈칸은 미기록, 0은 기록한 결과 0회입니다.

키퍼실점을 기존 선방으로 읽지 않습니다. 구양식의 `선방` 열은 호환되며, 같은 경기·팀·선수의 팀별 기록지 선방이 있으면 이를 우선하여 중복 합산하지 않습니다.

### 계산과 표시

| 지표 | 계산 | 대상 |
|---|---|---|
| 선방률 | 선방 ÷ (선방 + 키퍼실점) × 100 | 같은 경기·팀·선수의 선방과 키퍼실점이 모두 있는 경기 |
| 실점/15분 | 키퍼실점 합계 ÷ 수행시간 합계 × 15 | 키퍼실점·시간이 입력된 경기 |
| 선방/15분 | 선방 합계 ÷ 수행시간 합계 × 15 | 선방과 키퍼실점·시간이 연결된 경기 |

선방률은 시간으로 나누는 지표가 아닙니다. 선방+실점이 0이거나 자료가 부족하면 `—`입니다. 서로 다른 경기의 선방과 실점을 섞어 비율을 만들지 않습니다. 연결 경기 수와 60분 미만의 작은 표본을 함께 표시합니다.

**Player stats의 GOALKEEPER 분석** 및 **선수카드 → 선수 기록 → GOALKEEPER**에서 확인합니다. 팀 실점과 입력 키퍼실점 합계가 다르면 원본값으로 계산하되 경고 표시를 붙입니다. 잘못된 형식·연결 불가 기록은 운영 안내에서 확인합니다.

이번 버전은 골키퍼 지표를 분석용으로 추가했습니다. 실점 때문에 DEF/OVR이 자동으로 떨어지는 새 감점 규칙은 추가하지 않았습니다. 선방의 기존 DEF 성장 규칙은 유지합니다.

### 첨부 파일에서 발견한 사항

2026-10-02, 10R-B, 1경기:

- A특공대: 팀 실점 5골 / 임일규 입력 키퍼실점 3골. 나머지 2골의 배정을 확인하세요.
- 남진전: 키퍼실점 1골·15분은 있으나 선방이 빈칸입니다. 선방률을 산출하지 않습니다.
- 이성진: 별도 경기의 선방 2회는 있으나 키퍼실점·시간이 없습니다. 시간당 지표와 선방률을 산출하지 않습니다.

누락 값을 임의로 0으로 채우거나 팀 실점을 특정 선수에게 배정하지 않습니다.

## 4. 베스트커플 — 기본 점수 유지 + 기록 보너스

기본 점수는 기존과 같습니다.

`기본 = 동행 승률(%) × 0.5 + 동행 비율(%) × 0.3 + min(동행 경기당 본인 득점 × 33, 100) × 0.2`

`최종 = round(min(100, 기본 + 신규 기록 보너스))`

| 신규 지표 | 가중치 | 기록 경기당 두 선수 확인 합계의 기준 | 최대 보너스 |
|---|---:|---:|---:|
| 유효슛 | 25% | 4회 | 2점 |
| 키패스 | 25% | 3회 | 2점 |
| 수비성공 | 30% | 6회 | 2.4점 |
| 선방 | 20% | 4회 | 1.6점 |

각 항목의 보너스:

`8 × 가중치 × min(확인 합계/기록 경기 수/기준, 1) × min(기록 경기 수/5, 1) × (기록 경기 수/동행 경기 수)`

- **같은 경기·같은 팀으로 두 선수가 함께 출전한 경기**만 계산합니다. 상대팀 기록, 한 선수만 나온 경기, 팀명이 맞지 않는 입력은 제외합니다.
- 항목별로 둘 중 적어도 한 명의 명시 기록이 있는 경기를 기록 경기로 셉니다. 확인된 값만 합산합니다. 한 명의 빈칸을 측정된 0으로 바꾸지 않습니다.
- 기록이 충분하지 않으면 표본 및 기록률에 따라 가산이 작아집니다. 미기록이면 보너스 0으로 기존 점수를 유지합니다. 기록이 없는 과거 경기의 기본 점수를 깎지 않습니다.
- 총 가산 최대 8점, 최종 100점 상한입니다. 상한 때문에 실제 가산은 더 작을 수 있습니다.
- 표의 `신규 기록 · 동행 합계`, `기록 보너스`와 커플 분석 팝업에서 확인합니다. 정수 점수는 소량 가산에도 동일하게 보일 수 있습니다.
- 감독점수에는 이 보너스를 적용하지 않습니다.
- 기준 횟수·배점은 GGFC 초기 운영값이며 공인 평가 기준이 아닙니다. 이번 버전에서는 코드로 고정되어 있습니다.

## 5. DUO TYPE — 신규 기록을 축에 연결

항목별 **기록 경기당 평균**을 같은 시즌·조회 대회 내 선수들과 비교해 0~100 백분위로 환산합니다. 빈칸을 0으로 채우지 않고 명시 기록 경기만 분모로 사용합니다.

직접 반영 조건: **해당 항목 5경기 이상 기록 + 본인 출전 경기 대비 기록률 50% 이상 + 조건을 충족한 비교 선수 4명 이상**.

| 분석축 | 기존 축 | 신규 기록 |
|---|---:|---:|
| ATTACK | 80% | 유효슛 백분위 20% |
| CREATION | 75% | 키패스 백분위 25% |
| POWER | 70% | 수비성공 백분위 20% + 선방 백분위 10% |

없는 항목은 제외하고 사용 가능한 가중치를 다시 합계 100%로 맞춥니다. 예를 들어 선방 비교자료만 없으면 POWER의 기존 축:수비성공 비중은 70:20이므로 실제 정규화 비중은 약 77.8%:22.2%입니다. 신규 항목이 전부 부족하면 기존 축 계산을 유지합니다. 명시적인 0회는 측정값이므로 비교에 포함합니다.

SPEED·WORK의 직접 공식, 최종 유형점수의 **선수 특성 70% + 실제 동행 성적 20% + CHEMISTRY 10%**, 기존 20종 별명과 최소 동행경기 조건은 유지합니다. CHEMISTRY에는 갱신된 커플점수가 연결됩니다.

- 키패스는 실제 두 선수 사이의 연결 패스를 입증하지 않습니다. 별명은 확인된 기록으로 추정한 스타일입니다.
- 선방 횟수는 수비 관여도 지표이며 많다고 무조건 뛰어난 골키퍼라는 뜻은 아닙니다. 선방률·수행시간은 별도 골키퍼 분석으로 함께 보세요.
- 기존 SHO/PAS/DEF의 신규 기록 성장에도 간접 반영되므로 신규 축의 직접 효과와 완전히 독립적이지 않습니다. 이를 고려해 직접 비중을 제한했습니다.
- **사커비 원배점과 능력치 상승·하강 계수는 바꾸지 않았습니다.** 다만 신규 직접 지표를 사용할 수 있는 DUO 축에서는 기존 축의 상대적 비중이 줄어듭니다.
- 첨부 파일은 신규 기록이 선수별 소수 경기에만 있어, DUO 직접 반영 조건에 아직 미달합니다. 데이터 누적 전에는 `직접 반영 대기 (표본 부족)`가 정상입니다. 커플 가산은 표본 보정으로 작은 값부터 적용됩니다.

확인 위치: **Player Analysis → CHEMISTRY MAP 연결선 → DUO 팝업 → 시즌별 원자료·표본 확인 / 신규 4개 기록 반영 기준**. 관리자 **능력치 운영 안내**에도 같은 계산을 넣었습니다.
