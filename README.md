## Player Analysis 비교창

선수 비교 분석·커플점수 분석의 기준/상대 선수를 텍스트로 입력합니다. 전체 이름 또는 유일하게 일치하는 일부 이름을 입력하고 Enter/적용 버튼을 누릅니다. 여러 명이 일치하면 자동으로 임의 선택하지 않습니다. 추천 이름 목록 및 선수 바꾸기를 지원합니다.

유효슛·키패스·수비성공·선방을 합계, 해당 항목 기록 경기 수, 기록 경기당 평균으로 비교합니다. 미기록은 —, 명시적으로 입력한 0은 0회입니다. 선수 비교는 조회기간 전체, 커플 비교는 같은 팀으로 동행한 경기만 포함합니다. 기존 커플점수·DUO 산식은 변경하지 않았습니다.

## 골레이로 랭킹

Player Stats의 골키퍼 분석을 좌측·모바일 메뉴의 골레이로 랭킹으로 옮겼습니다. 선수카드 안의 개인 골키퍼 기록은 유지합니다. 현재 포지션이 GR이 아니어도 실제 키퍼 수행 기록이 있으면 대상입니다.

| 순위 선택 | 계산 | 기본 최소시간 |
|---|---|---|
| 실점/15분 (기본) | 키퍼실점 합계 ÷ 기록된 GR 분 × 15, 낮은 순 | GR 60분 |
| 선방/15분 | 선방·시간·실점 연결 경기의 선방 합계 ÷ 연결 GR 분 × 15, 높은 순 | 연결 GR 60분 |
| 선방률 | 연결 경기 선방 ÷ (선방+실점) × 100, 높은 순 | 연결 GR 60분 |

시즌·반기·순위 기준과 최소시간 0/30/60/90/120분을 선택합니다. 같은 실제 비율은 공동순위 1·1·3, 동률 안에서는 수행시간·이름순입니다. 빈칸·분모 0·시간 미달·실점 배정 확인 대상은 순위 없이 표시합니다. 표의 실점·선방 총계와 비율 산정에 사용한 연결 기록을 구분해 표시합니다. 표 아래 토글에 공식·조건·예시와 경기별 원자료를 제공합니다.

예: 같은 경기 집합에서 GR 60분, 실점 4, 선방 12 → 실점/15분 1.00, 선방/15분 3.00, 선방률 75%.
60분은 GGFC 운영용 기본 표본 기준입니다. 선방 수는 상대 슈팅 기회에도 영향을 받습니다. 랭킹 자체는 선수 능력치·카드 등급을 변경하지 않습니다.
