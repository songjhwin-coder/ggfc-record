# GGFC V3.25.25 · 메뉴 공개 관리

## 업데이트 적용

1. V3.25.24를 사용 중이면 `UPDATE_FROM_3.25.24.zip`의 변경 파일 6개를 같은 경로에 덮어씁니다.
2. 전체 파일이 필요하면 `LIGHT_FULL_32files.zip`을 사용합니다. 운영 중인 `firebase-config.js`, `database.rules.json`은 유지하세요. 이번 수정에서 두 파일은 변경하지 않았습니다.
3. 강력 새로고침 후 화면의 V3.25.25를 확인합니다. GitHub/Firebase에는 자동 배포하지 않았습니다.

변경 파일: `index.html`, `mobile.html`, `assets/ggfc-app.js`, `assets/ggfc-mobile.js`, `assets/ggfc.css`, `README.md`.
기존 경기기록, 선수 능력치, LONG FORM 및 카드 계산은 변경하지 않았습니다. Excel 원본·검증 데이터·사진 파일은 ZIP에 포함하지 않습니다.

## 관리자 사용 방법

관리자 로그인 → 왼쪽 ADMIN 영역의 **메뉴 공개 관리** → 메뉴별 **공개 / 비공개** 토글.

- 공개: 열람모드의 PC 왼쪽 메뉴, 모바일 하단 메뉴와 펼침 메뉴에 표시합니다.
- 비공개: 열람모드 메뉴에서 숨기며, 해당 메뉴 주소를 입력해도 공개된 메뉴로 이동합니다.
- 관리자는 공개 여부와 관계없이 모든 메뉴를 사용할 수 있습니다.
- 토글은 변경 즉시 기존 공유 저장 경로로 자동 저장합니다. 화면 상단의 **공유 저장 완료**를 확인하세요. 별도 저장 버튼은 없습니다.
- 서버 연결이 끊겼거나 관리자 인증이 없으면 변경을 적용하지 않습니다. 저장 중 연결이 끊기면 기존 공유 저장 재시도/미저장 내보내기 기능을 사용합니다.
- 연결된 열람 화면은 새로운 설정을 받으면 메뉴를 자동 갱신합니다. 현재 보고 있는 메뉴가 닫혔다면 공개된 메뉴로 이동합니다.

## 저장 범위와 동작

`DB.settings.menuVisibility`에 메뉴 ID별 true/false로 저장하며 기존 JSON 백업·복원 및 공유 DB 전송에 포함됩니다. 통합 Excel을 재업로드해도 공개 설정을 유지합니다. JSON 복원은 복원 파일에 담긴 설정을 따르며, 메뉴 설정이 없는 구버전 JSON은 기본값을 사용합니다.

이 기능은 **메뉴 노출과 앱 내 화면 이동 관리**입니다. 다른 공개 페이지에서 연결되는 선수카드나 공통 통계까지 별도로 숨기는 기능은 아닙니다. 기존 공개 기록 DB의 읽기 권한을 바꾸는 데이터 보안 기능도 아닙니다. Firebase 관리자 쓰기 권한과 인증 설정은 유지했습니다.

PC·390px 모바일에서 기본 공개 상태, 번호 제거, 토글 클릭/키보드 조작, 설정 저장 전달 및 직렬화, 관리자 전용 메뉴 보호, 직접 주소/이전 주소 이동, 로그아웃, 전체 메뉴 비공개, 실시간 설정 수신, 모바일 하단·펼침 메뉴 동기화를 확인했습니다. 실제 통합 Excel 282경기 재업로드 후에도 공개 설정이 유지되는 것을 확인했습니다. 운영 서버에 테스트 기록을 저장하거나 배포하지 않았습니다.

# 이전 V3.25.24 · LONG FORM 계산 안내

LONG FORM 기본 ON 및 기존 기록 소급 재계산 동작은 그대로 유지합니다. 아래는 이전 버전의 계산 설명입니다.

## 세 가지 값

| 구분 | 계산 및 역할 |
|---|---|
| BASE | 실제 PAC·SHO·PAS·DRI·DEF·PHY를 포지션별 가중평균한 장기 능력치 |
| FORM | 기존 최근 5R 계산 유지. 단계 −5~+5로 CURRENT OVR 보정 |
| LONG FORM | 최근 10R 각각의 시점에 계산한 FORM **원점수**를 −5~+5로 제한한 뒤 산술평균 |

한 R은 선수 소속팀에 실제 경기가 있었던 **경기일**입니다. 같은 날 여러 대진이 있어도 1R입니다. 경기 수 또는 달력 주 수가 아닙니다. 최초 4R의 FORM은 당시 확보된 자료로 계산합니다. LONG FORM 판정에는 최소 10R이 필요합니다. 날짜 조회 시 이후 기록은 사용하지 않습니다.

### 기존 FORM과의 관계

현재 기본 FORM은 출석 가산과 연속결석 감점의 영향이 큽니다. 최근 5R 모두 출전하면 출석 가산 +1.5이고, 경기성과 최솟값은 −1.5이므로 기본 설정에서 계속 출전하는 선수는 LONG FORM −2.5에 도달하지 않습니다. 이번 변경은 이 기존 FORM 산식을 바꾸지 않았습니다. 따라서 기본 설정에서는 장기 결석 또는 결석과 부진이 섞인 경우가 주 대상입니다. 출전 경기력만으로 별도의 슬럼프를 판정하려면 경기력 전용 지표 설계가 추가로 필요합니다.

## 기본 판정 기준

| LONG FORM | 기본 OVR 감소량 |
|---|---:|
| −1.5 초과 | 0 |
| −2.5 초과 ~ −1.5 이하 | 경고만 |
| −3.5 초과 ~ −2.5 이하 | 0.20 |
| −4.5 초과 ~ −3.5 이하 | 0.35 |
| −4.5 이하 | 0.50 |

- 최초 10R, 이후 14R·18R·22R…에서만 판정합니다. 반기가 바뀌어도 R 집계는 이어집니다.
- 현재 FORM 단계가 −1 이상이면 추가 감점을 즉시 중단합니다.
- 최근 10R의 소속팀을 확인할 수 없으면 감점하지 않습니다.
- 이미 감소한 능력치는 FORM이 회복되어도 자동 복구되지 않습니다. 이후 기존 성장 로직에 따라 회복합니다.
- 정수 CURRENT OVR는 반올림하므로 소폭 BASE 변화가 화면의 정수 OVR에 즉시 나타나지 않을 수 있습니다.

## 실제 감소량과 보호 장치

표의 감소량은 모든 선수에게 그대로 적용하는 고정 벌점이 아닙니다. 아래의 근거 비중·상한을 적용한 실제 감소량을 이력에 표시합니다.

### 1. 경기력 몫

`기본 감소량 × 최근 10R 중 출전했고 경기성과가 음수인 R 수 ÷ 10`

기존 FORM의 경기성과 부분(득점·도움·선방·MOM·개인파울·경기결과)을 사용합니다. 위 조건을 만족한 R 중 다음 근거에 해당하는 축만 조정합니다.

| 축 | 조정 근거 | 보호 조건 |
|---|---|---|
| SHO | 패가 승보다 많고 득점 없음 | 유효슛이 있으면 해당 R 제외 |
| PAS | 패가 승보다 많고 도움 없음 | 키패스가 있으면 해당 R 제외 |
| DEF | 개인파울 있음 | 수비성공 또는 선방이 있으면 해당 R 제외 |
| DRI·PHY | 경기력 몫에서 제외 | 드리블·턴오버·활동량 미기록을 실패로 만들지 않음 |
| PAC | LONG FORM 조정에서 항상 제외 | 기존 SoccerBee 및 기존 성장 로직 유지 |

SHO·PAS는 조건을 만족하는 R 수, DEF는 해당 R의 개인파울 수를 분배 가중치로 사용합니다. 근거가 없는 축으로 남은 감소량을 강제로 넘기지 않습니다.

### 2. 결석 몫

`기본 감소량 × 최근 10R 결석 비율 × 25%`

여기에서 **직전 4R에 기존 결석 로직으로 이미 차감된 실제 OVR 상당량**을 공제합니다. 공제 후 음수이면 0입니다. 활동 기록이 확인된 날은 결석 몫에서 제외합니다. 공식 참석수의 판정 기준 자체를 변경하지 않습니다.

남은 결석 몫은 PHY 가중치 1, SHO·PAS·DRI·DEF 각 0.5로 분배합니다. PAC는 제외합니다.

예: LONG FORM −3.8, 10R 모두 결석, 기존 결석 감점의 직전 4R OVR 합계가 0.028이면 추가 목표는 `0.35 × 1 × 0.25 − 0.028 = 0.0595 OVR`입니다. 축별 상한·능력치 최솟값·연간 한도에 걸리면 더 작아집니다.

### 3. 실제 능력치 감소 후 OVR 재계산

각 판정 연도의 포지션 가중치를 정규화해서 다음 조건으로 축별 감소량을 계산합니다.

`Σ(정규화된 포지션 가중치 × 각 능력치 감소량) = 실제 OVR 감소량`

- 축당 1회 최대 0.75점. 능력치 최솟값 이하로 내리지 않습니다.
- 배분이 불가능한 잔량은 차감하지 않습니다.
- 감소한 능력치에서 BASE OVR을 다시 계산합니다. OVR만 따로 빼서 저장하지 않습니다.
- 1~12월 연간 시즌의 **LONG FORM 직접 감소 합계** 최대 1.5 OVR. 반기 변경으로 초기화하지 않습니다.
- 이 한도는 기존 결석·개인파울·SoccerBee 재측정 하락까지 합친 전체 능력치 하락 한도는 아닙니다.
- 축별 성장률 구간이 달라질 수 있으므로 장기간 OFF/ON 결과 차이는 LONG FORM 직접 감소 합계와 약간 다를 수 있습니다.

## 화면과 관리자 설정

- 선수카드 아래: BASE / CURRENT / FORM / LONG FORM / 상태 / 시즌 조정 합계.
- 토글: 날짜·판정 R·LONG FORM·실제 OVR 상당 감소·축별 감소·판정 사유 이력 및 계산 기준.
- Player Ratings: BASE 셀과 모바일 카드에 LONG FORM 상태 표시.
- Record Stories: 선택 경기일에 실제 추가 하락이 발생한 선수의 SLUMP ALERT. 선수 이름을 누르면 카드가 열립니다. 하락량은 당일 성장까지 합산한 순변화와 구분합니다.
- 기존 OVR·능력치 변화 그래프는 조정된 능력치를 사용합니다.
- 관리자 → 선수 능력치 설정: ON/OFF, 표본 R, 판정 간격, 단계별 기준/감소량, 연간 한도, 결석 반영률, 축당 상한, 회복 기준을 변경할 수 있습니다. 저장 전에는 적용되지 않습니다. 잘못된 임계값 순서와 범위는 저장을 막습니다.
- 관리자 운영 안내와 Player Ratings 계산 설명도 업데이트했습니다.

## 검증 범위

V3.25.23과 비교하여 LONG FORM OFF일 때 첨부 DB의 282경기·공식 참석 4,106건·선수 66명의 기존 능력치, BASE, CURRENT, FORM 결과가 일치했습니다. 기본 ON에서는 현재 데이터상 8명에게 추가 조정이 발생하며 최대 LONG FORM 직접 감소 합계는 0.1246 OVR입니다. SoccerBee 측정 DB가 통합 Excel에 포함되지 않아 실제 측정 자료와의 결합 결과는 이 데이터 검증에 포함되지 않습니다.

별도 경계값 검증: 10R 이전 미적용, 10/14/18R 판정, 각 기준점, 회복 중단, 기존 결석 감점 공제, PAC 보존, 축별 최솟값·상한, 연간 한도·연도 전환, 신규 기록 보호, 소속 불명 보호, OFF 복귀, 반복 조회 중복 방지, 과거 조회, 관리자 설정 검증. PC와 모바일 카드·토글·스토리 표시도 확인했습니다.

V3.25.23의 선수 비교·골레이로 랭킹 및 이전 메뉴 기능을 유지합니다.
