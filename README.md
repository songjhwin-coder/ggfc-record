## GitHub 웹 적용 순서
1. 저장소에서 Code → Download ZIP으로 현재 소스를 백업합니다.
2. 제공 ZIP을 PC에서 압축 해제합니다. ZIP 자체를 저장소에 업로드하지 않습니다.
3. 저장소 최상위에서 Add file → Upload files를 선택합니다.
4. UPDATE: index.html, mobile.html, README.md, assets 폴더를 함께 드래그합니다. 폴더 경로를 유지합니다.
5. FULL: 위 파일과 assets 폴더를 적용하되 기존 firebase-config.js, database.rules.json은 그대로 둡니다. CNAME, .github 같은 개인 호스팅 파일도 보존합니다.
6. Commit changes 후 배포 브랜치에 반영합니다. 새 브랜치로 작업했다면 검토 후 배포 브랜치에 병합합니다.
7. Actions에서 Pages 배포 완료 후 사이트를 새로고침하여 V3.25.6을 확인합니다. 이전 화면이 남으면 Ctrl+F5로 다시 불러옵니다.
8. 관리자 데이터 업로드에서 Rev.4 통합 엑셀을 재업로드하고 공유 저장 완료 표시를 확인합니다. 능력치 운영 안내의 연결·점검 결과도 확인합니다.
9. 정상 동작을 확인한 다음 아래 구버전 파일을 각각 열어 우측 상단 메뉴 → Delete file → Commit changes로 정리합니다. assets 폴더 전체를 삭제하지 마세요.

## 수정한 문제
1. 팀별 기록지를 일반 출석 시트로 잘못 인식하여 경기 출석 전체를 덮어쓰던 오류를 수정했습니다. 새 전용 처리로 두 시트를 독립적으로 읽습니다.
2. 경기일 이전·당일의 최신 팀스쿼드 그룹이 리그 분류의 기준입니다. 슈퍼×슈퍼=슈퍼리그, 챌린지×챌린지=챌린지리그, 교차=인터리그입니다. 대회의 정규리그 원본 문자열은 보존하며 표시·필터·상세 창은 자동 분류를 사용합니다. 컵대회 등은 원래 명칭을 유지합니다.
3. 출석률 분모는 경기일별 소속팀과 참가 시작일, 실제 출전 기록을 반영합니다. 같은 경기의 출전은 한 번, 팀 누적 참석은 날짜·팀·선수별 한 번으로 계산합니다. 개인 득점에서 자책골·베네핏을 제외하며 팀 득점은 원본 점수를 유지합니다.
4. 선수 누적기록 및 경기 상세에 유효슛·키패스·수비성공을 표시합니다.
5. 관리자 능력치 운영 안내에 신규 공식, 현재 요율, 원본 득점 불일치, 신규 기록 연결 상태를 추가했습니다. 관리자 능력치 설정에서 가산과 상한을 변경할 수 있습니다.

## 팀별 기록지 연결과 보존
날짜 + 라운드 + 경기번호 + 이름을 실제 경기 출전 명단(선수1~15)과 연결합니다. 연결 가능한 경기·팀이 하나일 때만 반영합니다. 여러 건에 해당하거나 경기·출전이 없으면 미연결 상태로 보존합니다. 동일 키·동일 값 중복은 한 건, 다른 값의 중복은 업로드 오류로 처리합니다. 음수·소수 횟수는 허용하지 않습니다.

선방은 같은 경기·선수에 팀별 기록지 숫자가 있으면 그 값을 우선합니다. 0도 유효합니다. 빈칸이면 기존 경기기록 선방을 사용합니다. 두 값은 합산하지 않습니다. 신규 기록 원본은 기존 공유 설정 안에 보존하므로 Firebase 보안 규칙 변경이 필요 없습니다. JSON 공유·저장과 통합 엑셀 내보내기에서 유지됩니다.

## 신규 능력치 제안 기본값
|기록|능력|1회 기본 가산|일자별 기본 상한|
|---|---|---:|---:|
|유효슛|SHO|0.03|0.12|
|키패스|PAS|0.04|0.16|
|수비성공|DEF|0.03|0.18|
|선방|DEF|기존 선방 구간표|기존 선방 구간표|

신규 기본 가산 = min(일자별 횟수 × 1회 가산, 상한). 기존 출석·경기기록 가산에 더하고 승점 배율 × 현재 능력 구간 배율 × FORM 성장 배율을 적용합니다. 상한은 배율 적용 전입니다. 유효슛·키패스는 기존 득점·도움 보상에 소폭 추가하며 골·도움을 차감하지 않습니다. 신규 지표가 없던 과거 기록에 감점을 만들지 않습니다. 신규 세 지표는 FORM에 직접 추가하지 않으며 사커비 초기 평가 비중은 그대로입니다. 선방은 기존 FORM에도 반영되는 동일 선방값을 사용합니다.

- 화면 랭킹은 선택 시즌·반기의 범위를 사용하므로 위 연간 대조 총계와 구분해야 합니다.
