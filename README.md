변경 파일 7개: index.html, mobile.html, README.md, assets/ggfc-app.js, assets/ggfc-alltime.js, assets/ggfc-maker.js, assets/ggfc.css.

## 1. 경기기록 K열 승점삭감

- 실제 최신 양식: J 추가 파울 / K 승점삭감 / L 몰수패 / M 득점자 / N 도움 / O 개인파울 / P 키퍼실점 / Q MOM / R 득점자 열 검사 / S~AG 선수1~15.
- 열 번호에 고정하지 않고 헤더로 읽으므로 이전 양식의 경기기록도 호환됩니다.
- K열에 `3`을 입력하면 해당 행의 팀 누적승점에서 3점을 차감합니다. 빈칸과 0은 감점 없음입니다. 음수·소수·문자는 오류로 안내하고 업로드를 취소합니다.
- 팀 누적 승점 = 3 × 승 + 무 − 조회기간에 포함된 승점삭감 합계. 음수 승점도 그대로 표시합니다.
- 상대팀에는 차감하지 않습니다. 같은 감점을 여러 경기 행에 반복 입력하면 각각 별도 감점으로 누적됩니다. 한 번의 처분은 해당 팀의 한 행에만 입력하세요.
- 경기 스코어·승무패·득실·경기일 대진 카드·개인 승점·선수 능력치·베스트커플의 경기 결과에는 감점액을 넣지 않습니다.
- 팀 순위·팀 누적승점·누적 그래프·관련 팀순위 이미지에는 감점 후 점수를 사용합니다. 관리자 데이터 관리에는 감점 내역을 표시합니다.
- 대표승점 5·3·1에 감점액을 다시 직접 차감하지 않습니다. 구간 순위 계산에는 감점 후 팀 승점이 사용되며, 이미 확정한 대표승점 스냅샷은 유지됩니다. 과거 확정 구간에 감점을 추가해 대표승점 순위까지 바꾸려면 관리자가 해당 구간을 다시 확인·확정해야 합니다.
- Excel 내보내기는 K열에 원래 감점액을 저장합니다. 내보내기·재업로드를 반복해도 중복 차감하지 않습니다.
- 동일 경기의 중복 ID는 공통 검증 목록에서 한 번 계산합니다. 중복 경기의 감점값이 서로 다르면 충돌로 보류합니다.

## 2. Team Maker 상단 구분

자동 팀 편성 / 전술 라인업 버튼을 페이지 상단에 추가했습니다. 선택 중인 항목을 민트색으로 표시하며 PC·모바일에서 같은 방식으로 전환합니다. 기존 참석 예정 명단·게스트·편성 결과는 탭 전환 시 유지합니다. 좌측 메뉴와 모바일 하단 메뉴의 기존 진입 경로도 유지합니다.

## 3. All-Time Records 메달과 사진

상단 3명과 전체 표의 실제 1·2·3위에 금·은·동 메달을 표시합니다. 공동 2위는 모두 은메달이며 공동순위 다음 번호를 건너뛰는 기존 규칙을 유지합니다. 검색해도 전체 기준 순위는 바뀌지 않습니다.

사진 표시 크기를 가로·세로 각각 20% 확대했습니다. 표 사진 42→50.4px, PC 상단 사진 82→98.4px, 모바일 상단 사진 58→69.6px입니다. 사진 원본 URL과 이미지 비율은 유지합니다.

## 4. Weekly Best 5 상세 점수 토글

선수 이름·역할·총점은 항상 보입니다. 각 선수의 상세 경기기록, 항목별 점수, 선정 근거는 '상세 점수계산 보기'를 눌러 펼칩니다. 기본은 접힌 상태이며 전체·슈퍼리그·챌린지리그에 동일하게 적용됩니다. 선정 공식은 변경하지 않았습니다.

## 5. 역대 운영진 대시보드

- 최신 첨부의 실제 시트명 `역대 운영진`, 헤더 `운영년도`, `기수`, `이름(직무)1`~`이름(직무)8`을 인식합니다.
- 예: `2026~ / 5기 / 신인철(회장) / 천성집(총무) / 지태형(부총무) / 송재희(단장) / 이주현(총감독) / 김선오(코치)`.
- `2026~`는 종료년도 미정입니다. 한국 현재 연도에 해당하는 가장 최근 기수를 진행 중으로 표시하고 최상단에 배치합니다. 과거 기수는 최신 운영년도 순으로 표시합니다.
- 최신 첨부의 1~5기, 운영 참여자 중복 제외 16명을 연결합니다. 명단과 운영년도가 비어 있는 6기 행은 화면에서 제외하지만 Excel 내보내기 원본에는 보존합니다.
- 운영기간·기수·이름·직무, 현재 기수·현재 인원·전체 기수·역대 인원 요약을 표시합니다. 전역 대회·시즌 조회와 독립적으로 전체 운영 이력을 보여줍니다.
- 사진은 같은 이름의 역대기록 사진 및 선수명단 사진(URL)/배경삭제 URL에서 연결합니다. URL이 없거나 로딩에 실패하면 이름 첫 글자를 표시합니다. 로컬 사진 폴더는 추가하지 않았습니다.
- 해당 시트를 재업로드하면 운영진 이력을 파일 내용으로 교체합니다. 시트가 없는 구양식 업로드는 기존 운영진 이력을 유지하고, 헤더만 있는 빈 시트는 이력을 비웁니다.
- 잘못된 운영년도·이름(직무) 형식·같은 기수의 충돌 내용은 업로드를 취소하고 안내합니다. 이름이 현재 회원 명단에 없어도 운영진 이력에는 표시합니다.
- PC 좌측 메뉴와 모바일 메뉴에 역대 운영진을 추가했습니다. JSON 백업과 통합 Excel 내보내기에 포함됩니다.
