## Overview 조회기간 분리

| 화면 | 회원(열람모드) | 관리자 |
|---|---|---|
| 팀 순위 및 누적 기록 | DB 최신 경기일이 속한 시즌·반기·구간 누적 | 기존 경기기록 조회 구간(시즌·조회구간·반기구간) 적용 |
| 랭킹 조회기간 및 관련 랭킹 | DB 최신 경기일이 속한 반기 전체 누적 | 랭킹 전용 조회기간 적용 |
| 상대전적 | 경기결과에서 선택한 일자가 속한 반기 전체 | 상대전적 전용 조회기간 적용 |

랭킹 조회기간을 바꿔도 팀 누적표를 다시 그리지 않습니다. 팀 누적표와 랭킹은 각각의 기간을 표시합니다. 경기결과 날짜를 과거로 바꾸더라도 회원의 팀 누적표·랭킹 기준은 DB 최신 경기일을 유지합니다. 관리자는 기존 경기기록 조회를 통해 팀 누적표 기간을 변경할 수 있습니다. 대회 필터는 기존과 같이 적용합니다.

## 화면 변경

1. Record Stories: 다른 페이지와 동일한 공통 헤더 디자인을 사용합니다. 경기일 선택은 헤더 아래에 배치했습니다.
2. Player Stats: 각 선수의 ACHIEVEMENT를 접기/펼치기로 변경했습니다. 기본은 접힘이며, 전체 행 높이가 86px로 동일합니다. 펼친 행은 업적 내용을 보여주기 위해 확장됩니다.
3. 승급 진행률: 선수명 바로 오른쪽으로 옮기고 기존 210px 폭을 140px로 1/3 축소했습니다.
4. Player Stats 및 Player Ratings: 표에 세로 스크롤 영역을 적용하고 제목행을 고정했습니다. 표 안에서 아래로 스크롤하면 제목이 유지되며 가로 스크롤도 사용할 수 있습니다.
5. Player Stats 검색: 글자 입력마다 전체 능력치·커리어를 재계산하던 처리를 제거했습니다. 데이터나 조회기간이 바뀔 때 목록을 계산하고, 이름 검색은 이미 표시된 행을 필터링합니다. 한글 조합 중에는 불필요한 필터링을 피하고 조합 완료 시 적용합니다. 모바일 목록·골키퍼 분석·특이사항에도 같은 검색을 적용합니다.
6. Player Ratings: 최근 능력치 상승 선수 상자를 기본 접힘 토글로 바꿨습니다. 평가·시스템 열은 표의 맨 오른쪽으로 이동했습니다.
7. 기존 클래식 선수카드: 가로·세로 표시 크기를 각각 90%로 줄이고 카드 영역 안에 균형 있게 배치했습니다. 기존 내용 배치와 가로세로 비율을 유지하며 다른 프레임의 시각적 크기에 맞췄습니다. 선수 상세카드·스쿼드·디자인 미리보기에 함께 적용됩니다.

## 검증

기존 첨부 DB 270경기를 이용해 15개 기능 확인을 통과했습니다. 회원 최신 구간 48경기와 최신 반기 120경기가 분리되고, 관리자 랭킹 변경 시 팀 누적표가 유지되는 것을 확인했습니다. 선수 표 열·셀 일치, 접힌 행 높이, 검색 DOM 재사용, 표 제목 고정, Ratings 열 이동·토글 및 공통 헤더를 확인했습니다. 테스트 환경의 66명 필터링은 약 1ms였으며 실제 기기와 브라우저 환경에 따라 달라집니다.

기존 능력치·베스트커플·DUO 계산식과 저장 DB는 변경하지 않았습니다. 운영 Firebase 인증·쓰기와 GitHub 배포는 테스트하지 않았습니다.
