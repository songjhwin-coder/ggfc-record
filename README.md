## All-Time Records 상단 하위 메뉴

1. 전체 누적 기록 (기본): 2019~2025 역대기록의 통합값 + 2026-01-01 이후 경기기록.
2. 2019~2025 역대기록: 기존 원본의 통합 경기수, 통합 득점, 우승 기록을 그대로 표시합니다.

두 메뉴 모두 선수 사진, 이름 검색, 상위 3명, 6개 랭킹 지표와 공동 순위를 지원합니다. 전역 시즌/대회 필터의 영향을 받지 않습니다.

## 가산 기준

- 통합 득점 = 역대기록 통합 득점 + 2026년 이후 경기기록에서 해당 선수에게 기록된 득점. 자책골·베네핏은 개인 득점에서 제외합니다.
- 통합 경기수 = 역대기록 통합 경기수 + 2026년 이후 출석 선수 칸에 기록된 경기 수. 같은 날 여러 경기에 출전하면 각각 셉니다. 한 경기의 중복 출석은 1회입니다.
- 모든 대회와 2027년 이후 기록도 동일하게 포함합니다. 현재 명단 등록 여부나 선수 시작일로 과거의 실제 입력 기록을 제외하지 않습니다.
- 득점 기록만 있고 출석이 없으면 득점만 더합니다. 출전을 임의로 추정하지 않습니다.
- 실제 경기ID와 해당 경기의 팀에 연결되는 기록만 사용합니다. 팀이 없거나 불일치하는 행, 연결되지 않는 경기ID는 가산하지 않습니다.
- 같은 날짜/대회/라운드/경기번호/양 팀의 중복 경기ID는 동일 경기로 처리합니다. 중복 경기의 선수 득점이 다르면 큰 값을 한 번 적용하고 관리자에게 확인을 안내합니다.
- 2026년부터 등장한 선수는 과거값을 0으로 시작하여 포함합니다. 기존 역대기록에 있으나 통합값과 연도별 값이 모두 미입력인 선수는 합계를 —로 유지하고 이후분만 별도로 보여줍니다.
- 전체 누적 표의 경기수·득점 아래에 `19~25 기존값 / 26~ +추가값`을 표시합니다.
- 우승 횟수는 2019~2025 원본만 유지합니다. 이번 버전은 2026년 이후 리그·FA컵·챔스 우승 자동 판정을 추가하지 않았습니다.

## 보관 자료 관리 / 중복 방지

- 역대기록 시트는 2019~2025 자료로 고정하여 관리합니다. 해당 범위 밖의 연도별 경기수·득점 열이 있으면 업로드를 중단합니다. 통합값에도 2026년 이후분을 수동으로 더하지 마세요.
- 과거 원본은 DB.settings.allTimeRecords에 보존하고, 이후분은 조회 시 경기기록으로 계산합니다. 누적 결과를 원본에 덮어쓰지 않습니다.
- 경기기록을 수정·삭제 후 재업로드하면 가산분도 다시 계산합니다.
- 역대기록 시트가 없는 업로드는 기존 보관 자료를 유지합니다. 헤더만 있는 빈 역대기록 시트는 보관 자료만 비웁니다. 이후 경기기록은 남습니다.
- 통합 엑셀 내보내기의 역대기록 시트에는 보관 원본만 출력합니다. 재업로드해도 이후분이 중복 가산되지 않습니다.
- 관리자에게만 원본 합계 불일치와 관리 안내가 보입니다. 첨부 DB의 이상호 경기수 21 / 연도별 합계 32 차이는 기존 입력값 21을 유지합니다.
